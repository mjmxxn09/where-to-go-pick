# 앱 아이콘

이 앱용으로 새로 그린 아이콘(픽클 캐릭터·회사 그림 아님). 보라 바탕(#6A4CF5 계열) + 지도 핀 + 가볼 곳 별 + 점선 길.

- `app_icon.svg`: 원본
- `app_icon_1024.png`: 스토어·앱 런처 아이콘 만들 때 원본으로
- `app_icon_128.png`: 카카오 디벨로퍼스 [앱] > [일반] > 앱 기본 정보의 앱 아이콘(250KB 미만, 128×128 이하)

다시 만들기: `rsvg-convert -w 1024 -h 1024 app_icon.svg -o app_icon_1024.png` (128도 같은 방법)
