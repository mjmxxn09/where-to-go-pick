# 여행 중 장소 목록 개편 (2026-11-23)

요청: "장소 리스트가 너무 별로 — 지역별·카테고리별 인기 5곳만 보여 주고, 나머지는 카카오맵 검색으로 추가".

## 무엇이 문제였나

- 한국관광공사(TourAPI) 지역 목록을 100곳 가까이 받아 칩(전체·명소·자연·문화·놀거리·맛집·카페)으로 나눠 보여 줬다.
  순서가 "사진 있는 곳 먼저"라 인기와 상관이 없고, 맛집·카페는 수가 적고 오래된 곳이 섞였다.
- 검색도 TourAPI 키워드라 실제 가게(카페 지점, 동네 식당)를 거의 못 찾았다.

## 어떻게 바꿨나

| 자리 | 전 | 후 |
|---|---|---|
| 위쪽 목록 | 칩 7개 × 수십 곳 | **인기 장소** — 명소·맛집·카페·문화 칸마다 그 시·군·구 5곳, 1~5위 번호 |
| 검색 | TourAPI 키워드 30곳 | **찾아서 담기** — 카카오맵 키워드 15곳씩 + 더 보기(최대 45곳) |
| 장소 정보 | 이름·종류만 | 이름을 누르면 카카오맵 장소 페이지(사진·리뷰·영업시간·길찾기) |
| 출처 | 없음 | 목록 아래 "장소 정보: 카카오맵" / "한국관광공사" |

- 인기 기준: 카카오 로컬 키워드 검색의 정확도순(`가볼만한곳`·`맛집`·`카페`·`박물관 미술관` + 지역 이름)에서 **그 시·군·구 주소인 곳만** 남겨 앞 5곳. 6시간 캐시라 하루 호출 수가 적다.
- 검색: 지역 이름을 붙여 먼저 찾고, 그 지역 결과가 없으면 전국 결과를 보여 주며 "○○에서는 못 찾아서 다른 지역 결과" 안내.
  같은 장소가 다음 쪽에 또 오면 한 번만, 검색어를 바꾸면 늦게 온 이전 결과는 버린다.
- 가볼 곳(☆)에 담으면 카카오맵 주소도 같이 저장돼, 가볼 곳 목록에서도 이름을 눌러 상세를 연다.
- 안전: 앱은 `http(s)://place.map.kakao.com/…` 주소만 연다(서버 응답이 이상해도 다른 사이트로 보내지 않음). 카카오 키는 서버(Supabase 비밀값)에만 있다.
- 카카오 키가 없을 때: 서버가 TourAPI 목록에서 칸마다 앞 5곳을 대신 준다. 화면은 같고 출처 줄만 "한국관광공사".
