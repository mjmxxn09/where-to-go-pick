# 여행 중 장소 목록 개편 (2026-11-23)

요청: "장소 리스트가 너무 별로 — 지역별·카테고리별 인기 5곳만 보여 주고, 나머지는 카카오맵 검색으로 추가".

## 무엇이 문제였나

- 한국관광공사(TourAPI) 지역 목록을 100곳 가까이 받아 칩(전체·명소·자연·문화·놀거리·맛집·카페)으로 나눠 보여 줬다.
  순서가 "사진 있는 곳 먼저"라 인기와 상관이 없고, 맛집·카페는 수가 적고 오래된 곳이 섞였다.
- 검색도 TourAPI 키워드라 실제 가게(카페 지점, 동네 식당)를 거의 못 찾았다.

## 어떻게 바꿨나

| 자리 | 전 | 후 |
|---|---|---|
| 위쪽 목록 | 칩 7개 × 수십 곳 | **인기 장소** — 명소·맛집·카페·문화 칸마다 그 시·군·구 5곳, 1~5위 번호 |
| 검색 | TourAPI 키워드 30곳 | **찾아서 담기** — 카카오맵 키워드 15곳씩 + 더 보기(최대 45곳) |
| 장소 정보 | 이름·종류만 | 이름을 누르면 카카오맵 장소 페이지(사진·리뷰·영업시간·길찾기) |
| 출처 | 없음 | 목록 아래 "장소 정보: 카카오맵" / "한국관광공사" |

- 인기 기준: 카카오 로컬 키워드 검색의 정확도순(`가볼만한곳`·`맛집`·`카페`·`박물관 미술관` + 지역 이름)에서 **그 시·군·구 주소인 곳만** 남겨 앞 5곳. 6시간 캐시라 하루 호출 수가 적다.
- 검색: 지역 이름을 붙여 먼저 찾고, 그 지역 결과가 없으면 전국 결과를 보여 주며 "○○에서는 못 찾아서 다른 지역 결과" 안내.
  같은 장소가 다음 쪽에 또 오면 한 번만, 검색어를 바꾸면 늦게 온 이전 결과는 버린다.
- 가볼 곳(☆)에 담으면 카카오맵 주소도 같이 저장돼, 가볼 곳 목록에서도 이름을 눌러 상세를 연다.
- 안전: 앱은 `http(s)://place.map.kakao.com/…` 주소만 연다(서버 응답이 이상해도 다른 사이트로 보내지 않음). 카카오 키는 서버(Supabase 비밀값)에만 있다.
- 카카오 키가 없을 때: 서버가 TourAPI 목록에서 칸마다 앞 5곳을 대신 준다. 화면은 같고 출처 줄만 "한국관광공사".

## 이어서: 걸은 길 기록 빼기, 가볼 곳 지도 (같은 날)

요청: "여행 중에 걸은 길 빼 줘. 가볼 곳 담으면 그 위치를 가볼 곳 위에 지도로".

### 걸은 길 기록 — 뺌
- 여행 중 화면의 "걸은 길 기록" 스위치와 컨트롤러의 켜기/끄기 상태를 지웠다. 실제로 위치를 기록하던 코드는 없었다(스위치만 있었음).
- 이제 앱은 폰 위치(GPS)를 쓰지 않는다. 문서(README, product, architecture, supabase, 출시 체크리스트)도 맞췄다.

### 가볼 곳 지도 — 새로
- 가볼 곳 목록 위에 이 시·군·구 모양 지도(주변 시·군·구는 흐리게)를 놓고, 담은 순서대로 **번호 핀**을 찍는다.
  보라 = 갈 곳, 청록 = 다녀옴. 핀을 누르면 아래에 "2. 오죽헌". 목록에도 같은 번호·색 동그라미.
- 지도 그림은 앱에 이미 든 통계청 경계(내 지도·여행지 고르기와 같은 그림)라 **지도 키·인터넷·요금이 필요 없다**.
- 위경도 → 앱 지도 좌표: 지도 데이터에 투영 값이 남아 있지 않아, 같은 경계의 위경도 원본(southkorea-maps)과
  시·군·구 무게중심을 맞춰 도마다 1차식을 구했다(`lib/features/korea_map/geo_projection.dart`, 다시 구하는 법 `tool/fit_geo_projection.py`).
  무게중심 오차는 대부분 0.5칸 이하 — 경복궁·해운대·전주 한옥마을·화성행궁 등이 그 구·시 안에 찍히는지 테스트(`test/planned_map_test.dart`).
  해안선은 단순화돼 있어 바닷가 장소는 바다 쪽에 살짝 걸칠 수 있다. 옮겨 그린 섬(옹진군 등)은 어긋날 수 있다.
- 좌표: 서버 `life` 함수가 장소마다 `lat`·`lng`(한국 안 좌표만, 소수 6자리)를 보낸다. 가볼 곳에 담을 때 같이 저장(폰·Supabase `planned` JSON, 마이그레이션 없음).
  이 변경 전에 담은 곳은 좌표가 없어 목록에만 나오고, 지도 아래에 "지도에 없는 곳 n곳"으로 센다. 다시 담으면 찍힌다.
- 검색에서 다른 지역 장소를 담으면(지역 크기의 40% 넘게 밖) 지도에 그리지 않고 같은 줄에 센다.

## 이어서: 도·광역시 전체로도 여행 만들기 (같은 날)

요청: "구까지 선택하지 않고도 시·도 단위로도 선택 가능하게".

- 여행지 고르기에서 도를 누르면 **그 도·광역시 전체가 바로 골라진다**(카드: "대전광역시 · 전체"). 시·군·구를 누르면 좁혀지고,
  고른 시·군·구를 한 번 더 누르면 다시 전체. 지도 위 칩도 "대전광역시 전체".
- 여행 id는 도 코드 두 자리(예: `25`), 제목은 짧은 이름("대전 여행", "강원 여행"). 마이그레이션 없음.
- 서버 `life`: `cityName`이 비면 도 전체 — 카카오 인기·검색은 "대전 맛집"처럼 도 이름으로 찾고 그 도 주소만, 관광공사는 도 코드만, 날씨는 도 관광지 가운데.
- 가볼 곳 지도: 도 전체 모양에 핀.
- 내 지도: 전국 지도에선 그 도가 칠해지고, 도 상세에선 **체크인한 가볼 곳이 든 시·군·구**를 칠한다(좌표를 아는 곳만).
- 테스트: 서버 `matchCity`·`inRegion`·`regionWord`·도 전체 검색, 앱 `citiesFromWholeProvinceTrips`·짧은 이름.
