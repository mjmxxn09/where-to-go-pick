# 제품 개요

## 한 줄

여행 갈 때 그 지역 명소·맛집과 그날 날씨를 보고, 다녀온 곳을 시간순으로 체크인해서 지도와 여행 노트로 남기는 앱. 픽클 캐릭터 세계관과 픽클 계정·투표를 함께 쓴다.

## 흐름

1. **여행지 고르기**: 픽클 관심사 → 도 → 시·군·구 → 그날 날씨 요약 → 여행 만들기
2. **여행 중**: 명소/맛집 추천(TourAPI + 픽클 투표 결과) → 장소에서 버튼 한 번 체크인 → 원할 때만 걸은 길 기록
3. **여행 카드**: 체크인을 시간순으로 길 위에 배치한 모눈종이 노트. 한 장 또는 하루씩(폴더). 이미지 저장·공유
4. **내 여행 지도**: 다녀온 시·군·구가 색칠되고 시·도 색칠 현황이 쌓임
5. **(2차) 동네 산책**: 여행이 없는 날에도 열 이유

## 차별점

- **픽클 투표로 고르는 맛집·명소**: 공개 데이터만으로는 "진짜 맛집"을 고르기 어렵다. 픽클 투표 결과("강릉 장칼국수 A vs B")를 추천 근거로 쓰고, 다녀온 사람이 투표를 만들면 다시 픽클로 사람이 돌아온다.
- **색칠 수집**: 다녀온 시·군·구를 채우는 재미. 픽클 친구 성장·배지와 연결할 수 있다(서버 정책 필요).
- **여행 노트 카드**: 손그림 아이콘과 손글씨로 꾸민 한 장짜리 기록. 공유되는 결과물이 곧 홍보물.

## 비슷한 서비스(2026-11 확인)

- 떠나가챠: 도 → 시 랜덤 뽑기, 방문 지역 지도 체크 — 고르기·색칠이 겹친다
- 어디(EODI): AI 일정·자동 기록
- Polarsteps: 해외 여행 경로 자동 기록(대형)

## 1차 범위

여행지 고르기, 여행 중(날씨·추천·체크인), 여행 카드(한 장/폴더), 내 여행 지도. 자동 경로 추적·포인트 적립·산책은 2차.

## 열린 질문

- 앱 이름 확정(현재 '어디갈지 Pick!'), 상표 확인
- 픽클 캐릭터 이미지·이름 사용 승인 범위(이 저장소에는 캐릭터 이미지를 넣지 않았다)
- 회사 프로젝트로 진행할지 개인 프로젝트로 둘지 — 저장소 소유 위치와 픽클 API 사용 권한이 달라진다
