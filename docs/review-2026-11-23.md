# 앱 전체 검토 (2026-11-23)

화면마다 코드를 다시 읽고, 고칠 것은 바로 고쳤다. 남은 것은 맨 아래 "다음에 할 것".

## 고친 것

### 동기화·네트워크
- **서버에 올리는 순서가 뒤집힐 수 있던 문제** — ☆를 빠르게 여러 번 누르거나 가볼 곳 순서를 끌어 바꾸면, 바뀔 때마다
  올리기를 따로 보내서 늦게 끝난 옛 상태가 새 상태를 서버에서 덮어쓸 수 있었다. 게다가 다음 동기화가 "가볼 곳 개수"만 비교해서
  순서·날만 다른 건 다시 올리지 않았다 → 다른 폰에서 로그인하면 옛 순서가 보였다.
  - 올리기를 한 줄로 세웠다(한 번에 하나, 기다리는 동안 바뀐 건 최신 상태만 모아서).
  - 동기화 비교에 가볼 곳 순서·날, 체크인 시각까지 넣었다.
- **응답이 안 오면 끝없이 돌던 로딩** — 모든 서버 요청(Supabase·픽클)에 20초 제한(`TimeoutClient`).
  앱을 열 때 로그인 확인은 8초, 로그아웃 전 동기화도 8초까지만 기다린다(스플래시가 멈춘 것처럼 보이던 경우).

### 여행지
- **지역 이름이 한 글자로 잘리던 문제** — "중구 → 중", "동구 → 동"(여행 제목, 후보 줄, 투표 질문 모두).
  한 글자만 남으면 자르지 않고, 여러 도시에 있는 두 글자 구에는 도 이름을 붙인다: **"대전 중구 여행"**.
- **후보 줄** — 담은 후보가 칩으로 보이고, 누르면 지도에서 그 지역, ✕로 하나씩 뺀다(전에는 지도에서 다시 찾아 ♡를 눌러야 했다).
  다섯 번째를 담아 첫 후보가 빠지면 알려 준다.
- **투표 1위로 여행 만들기** — 카드는 1위 지역으로 바뀌는데 지도는 이전 지역에 머물던 것을, 지도도 함께 옮겼다.
- 최근 물어본 투표 줄에 그 투표의 질문을 보여 준다.

### 여행 중
- **인기 장소 '다시 시도'가 고른 날·검색을 지우던 문제** — 인기 장소만 다시 받게 했다.
- 날씨를 못 받으면 '다시 시도', 화면을 오래 켜 두면 한 시간마다 지금 날씨를 새로 받는다.
- **정한 기간이 지났는데 여행 중으로 남아 있으면** 안내 + "여행 마치기 / 기간 늘리기" 버튼.
- 픽클이 질문 답을 못 보내면 말풍선을 닫고 알려 준다(전에는 조용히 실패).
- 체크인 기록의 날 머리말에 날짜(1일차 · 11월 23일 (월)).

### 투표
- **"지금 마감하기"를 한 번 묻는다**(되돌릴 수 없어서).
- "링크 복사" → **"친구한테 보내기"**(공유 시트로 질문 + 링크, 길게 누르면 복사).
- **예시 투표임을 알린다** — 투표는 아직 픽클 서버 없이 예시로만 돈다(친구 표는 고정 예시, 앱을 다시 켜면 사라짐, 링크는 열리지 않는 주소).
  그래서 투표 화면 위에 안내를 띄우고, 예시일 때는 링크를 보내지 않는다. 체크인 질문의 "+10P"도 예시일 땐 보여 주지 않는다.
- 표 넣기·마감이 실패하면 알려 준다.

### 문구
- 받침에 맞는 조사(`lib/core/text/josa.dart`): "양양군**으로** 여행 만들기", "강릉**은** 뺐어요", "픽클이**랑** 다닌 곳".

### 내 지도
- 색칠 현황에 "시·군·구 n곳"도 함께.
