# 여행 노트(여행 카드) 배치 규칙

코드: `lib/features/trip_card/trip_card_layout.dart` (순수 계산, `test/trip_card_layout_test.dart`)

## 길

- 체크인을 **시간순**으로 한 줄에 3곳씩 놓는다. 장소 자리는 길을 가로지르는 짧은 눈금으로 표시한다.
- 줄은 왼→오, 오→왼을 번갈아 간다. 줄 끝에서 반원(지름 140)으로 꺾여 다음 줄로 내려간다.
- 줄 수 = ⌈체크인 수 / 3⌉, 페이지 높이 = 170 + (줄 수 − 1) × 140 + 150.
- 출발 핀은 첫 줄 왼쪽 끝, 끝 깃발은 마지막 줄의 진행 방향 끝. 둘 다 글자 없이 그림만.
- 글꼴은 감자꽃(Gamja Flower). 제목(예: "강릉 1일차") 29px, 그 아래 날짜 15px, 사이 약 9px.

## 장소 이름

- 길 **아래·위를 번갈아** 쓴다(첫 장소는 아래). 같은 쪽 이웃은 두 칸 떨어져 있어 이름 폭을 넓게(약 95px) 쓰고도 이름 사이가 18px 이상 띈다.
- 순서: 아래쪽은 눈금 → 시간 → 이름, 위쪽은 이름 → 시간 → 눈금(위로 쌓음).
- 장소 이름 13px(감자꽃). 폭을 넘으면 **띄어쓰기 단위로** 두 줄까지 줄바꿈("안목 / 커피거리"), 그래도 안 되면 11px까지 줄이고 마지막엔 말줄임(…). `wrapByWords`
- 한 장에 여러 날이면 그날 첫 장소의 시간에 "2일차 08:30"처럼 붙인다. 눈금·시간 색: 1일차 보라, 2일차 자주, 3일차 청록(이후 반복).

## 스티커 — 유저가 직접 붙인다

코드: `card_stickers.dart`(모델·저장, `test/card_stickers_test.dart`), `trip_card_editor.dart`(붙이기·옮기기), `sticker_tray.dart`(서랍)

- 카드는 **길·시간·장소 이름만** 그린 빈 카드로 시작한다. 제목 옆 작은 잎 그림만 고정.
- 아래 **스티커 서랍**: 분류(해변·카페·문화유산·시장·맛집·수산시장·자연·숙소·이동) 칩 + 가로 목록.
  - 누르면 카드 가운데 근처에 붙는다(여러 번 누르면 조금씩 비켜 붙음).
  - 위로 끌어 카드 원하는 자리에 놓을 수도 있다(가로로 밀면 목록이 넘어감).
- 카드 위에서
  - 스티커 누르기: 고르기(맨 위로 올라옴, 보라 테두리). 빈 곳 누르기: 해제
  - 한 손가락 끌기: 옮기기 / 두 손가락: 크기(28~240)·회전
  - 고르면 아래 도구 막대: 작게·크게·왼쪽/오른쪽 15° 돌리기·떼기·완료(마우스로 쓰는 웹에서도 조절 가능)
- **장소 막대**(눈금+시간+이름): 끌면 손가락을 따라 길 위로 옮겨진다. 위아래로 끌면 가장 가까운 줄로 붙고(`nearestRow`, 2026-11-23부터 다른 줄로도), x는 그 줄 곧은 구간 안·이름이 카드 밖으로 안 나가게 맞춘다(`stopDragRange`). 옮긴 줄은 `StopEdit.row`로 저장. 누르면 도구 막대: 이름 위·아래 뒤집기 · 원래 자리 · 완료. 카드마다 체크인 id별로 저장(키 `trip_card_stops.v1`).
- 상단 ✨ **자동으로 꾸미기**: 장소마다 어울리는 스티커를 그 장소 바로 옆, 이름표 반대쪽 길가에 붙인다(이름이 아래면 위, 위면 아래). 크기 54, 장소 막대 가운데, 길에서 4 띄움. 다른 이름표·제목·출발 핀·끝 깃발·먼저 붙인 스티커와 겹치면 좌우로 10·20 비켜 보고, 안 되면 그 장소는 건너뛴다. 옮긴 장소 막대 자리를 따른다. 이미 붙인 게 있으면 묻고 바꾼다.
  - 고르는 법(`place_sticker_match.dart`): 이름에 든 말(순두부→찌개, 수산시장→회, 수목원→숲, …) → 절 이름(…사)은 탑 → 종류 대표 그림. 같은 카드에서 같은 그림은 되도록 겹치지 않게.
  - 어떻게 다녔는지 모르니 자동차·발자국 같은 이동 스티커는 자동으로 붙이지 않는다(서랍에서 직접).
- 상단 **모두 떼기**: 이 카드의 스티커를 모두 뗀다(확인 후).
- 저장: 카드 한 장마다 따로, 기기에(shared_preferences, 키 `trip_card_stickers.v1`) 저장하고 Supabase `card_decorations`에도 올린다([supabase.md](supabase.md)). "한 장에 모아보기"와 "하루씩 나눠보기"의 각 장은 배치가 달라 서로 다른 장으로 저장된다.
- 좌표는 카드 좌표(가로 358) 기준 스티커 중심·한 변 길이·회전(라디안).
- 카드와 스티커는 `RepaintBoundary` 안에 있어 이미지 저장·공유에 함께 담긴다. 고를 때 보이는 테두리는 바깥이라 담기지 않는다.
- 장소 눈금은 x 94~264 범위(칸 간격 약 57px)에만 놓아 반원 안쪽에 스티커 붙일 여백을 남긴다.

## 보기 방식

- **한 장에 모아보기**: 모든 날을 한 장에. 하단 요약 문구는 없음(스티커 붙일 여백)
- **하루씩 나눠보기**: 날마다 한 장, 폴더로 묶음.
- 당일 여행은 항상 한 장
- 종이: 모눈 / 점 / 무지

## 이미지 저장·공유 (2026-11-20)

코드: `lib/features/trip_card/export/`, 버튼은 `trip_card_screen.dart`.

- `RepaintBoundary`를 3배 해상도 PNG로 찍는다(스티커 포함, 고를 때 테두리 제외). 나눠 보기는 장을 하나씩 띄워 찍고 원래 장으로 돌아온다.
- **이미지 저장**: Android·iOS는 사진 갤러리의 "어디갈지 Pick" 앨범(`gal`), 웹은 PNG 다운로드(조건부 import로 갈림). 나눠 보기면 "N장 모두 저장".
- **공유하기**: 투표 후보 핀이 2곳 미만이면 지금 장 이미지를 공유 시트로(`share_plus`, 웹은 Web Share API 또는 다운로드). 핀이 2곳 이상이면 지금처럼 "투표로 공유".
- 파일 이름: `어디갈지Pick_강릉_여행(_2일차).png`
- 플랫폼 설정
  - Android(`android/`는 아직 저장소 밖): `WRITE_EXTERNAL_STORAGE`(`maxSdkVersion="29"`)와 `<application android:requestLegacyExternalStorage="true">`. Android 10 이상은 권한 창 없이 저장.
  - iOS(`ios/` 만들 때): `Info.plist`에 `NSPhotoLibraryAddUsageDescription`, 앨범 저장이라 `NSPhotoLibraryUsageDescription`도. 예: "여행 카드를 사진첩에 저장해요."
