# 여행 노트(여행 카드) 배치 규칙

코드: `lib/features/trip_card/trip_card_layout.dart` (순수 계산, `test/trip_card_layout_test.dart`)

## 길

- 체크인을 **시간순**으로 한 줄에 2곳씩 놓는다.
- 줄은 왼→오, 오→왼을 번갈아 간다. 줄 끝에서 반원(지름 120)으로 꺾여 다음 줄로 내려간다.
- 체크인이 늘면 줄 수 = ⌈체크인 수 / 2⌉ 만큼 늘고, 페이지 높이 = 첫 줄 y + (줄 수 − 1) × 120 + 160.
- 출발 핀은 첫 줄 왼쪽 끝, 끝 깃발은 마지막 줄의 진행 방향 끝.

## 장소 한 곳

| 요소 | 위치 |
|---|---|
| 점 | 길 위 |
| 시간 | 점 위 30px. 한 장에 여러 날이면 그날 첫 장소에 "2일차 · 08:30" |
| 이름 | 점 아래 12px, 손글씨 21px |
| 손그림 아이콘 | 이름 아래, 56×42 |

날짜별 점·시간 색: 1일차 보라, 2일차 자주, 3일차 청록(이후 반복).

## 장소 종류 → 아이콘

해변(파라솔·파도), 카페(커피잔), 문화유산(한옥·대나무), 시장(천막), 맛집(그릇), 수산시장(생선), 자연(소나무), 기타(별).
종류는 TourAPI 분류와 체크인 시 사용자가 고른 값으로 정한다(매핑은 생활 서버).

## 보기 방식

- **한 장에 모아보기**: 모든 날을 한 장에. 하단에 "다녀온 곳 N곳 · M일 동안"
- **하루씩 나눠보기**: 날마다 한 장, 폴더로 묶음. 2일차부터는 "숙소 출발", 끝은 "N일차 끝!"
- 당일 여행은 항상 한 장
- 종이: 모눈 / 점 / 무지
