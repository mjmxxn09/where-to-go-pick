# 여행 노트(여행 카드) 배치 규칙

코드: `lib/features/trip_card/trip_card_layout.dart` (순수 계산, `test/trip_card_layout_test.dart`)

## 길

- 체크인을 **시간순**으로 한 줄에 3곳씩 놓는다. 장소 자리는 길을 가로지르는 짧은 눈금으로 표시한다.
- 줄은 왼→오, 오→왼을 번갈아 간다. 줄 끝에서 반원(지름 140)으로 꺾여 다음 줄로 내려간다.
- 줄 수 = ⌈체크인 수 / 3⌉, 페이지 높이 = 170 + (줄 수 − 1) × 140 + 150.
- 출발 핀은 첫 줄 왼쪽 끝, 끝 깃발은 마지막 줄의 진행 방향 끝.

## 장소 이름

- 길 **아래·위를 번갈아** 쓴다(첫 장소는 아래). 같은 쪽 이웃은 두 칸 떨어져 있어 이름 폭을 넓게(약 95px) 쓸 수 있다.
- 순서: 아래쪽은 눈금 → 시간 → 이름, 위쪽은 이름 → 시간 → 눈금(위로 쌓음).
- 손글씨 17px. 폭을 넘으면 **두 줄**로 줄바꿈, 그래도 넘치면 13px까지 줄이고 마지막엔 말줄임(…).
- 한 장에 여러 날이면 그날 첫 장소의 시간에 "2일차 08:30"처럼 붙인다. 눈금·시간 색: 1일차 보라, 2일차 자주, 3일차 청록(이후 반복).

## 스티커 — 유저가 직접 붙인다

코드: `card_stickers.dart`(모델·저장, `test/card_stickers_test.dart`), `trip_card_editor.dart`(붙이기·옮기기), `sticker_tray.dart`(서랍)

- 카드는 **길·시간·장소 이름만** 그린 빈 카드로 시작한다. 제목 옆 작은 잎 그림만 고정.
- 아래 **스티커 서랍**: 분류(해변·카페·문화유산·시장·맛집·수산시장·자연·이동) 칩 + 가로 목록.
  - 누르면 카드 가운데 근처에 붙는다(여러 번 누르면 조금씩 비켜 붙음).
  - 위로 끌어 카드 원하는 자리에 놓을 수도 있다(가로로 밀면 목록이 넘어감).
- 카드 위에서
  - 스티커 누르기: 고르기(맨 위로 올라옴, 보라 테두리). 빈 곳 누르기: 해제
  - 한 손가락 끌기: 옮기기 / 두 손가락: 크기(28~240)·회전
  - 고르면 아래 도구 막대: 작게·크게·왼쪽/오른쪽 15° 돌리기·떼기·완료(마우스로 쓰는 웹에서도 조절 가능)
- 상단 ✨ **자동으로 꾸미기**: 길이 꺾이는 반원 안쪽에 그 줄 마지막 장소 종류의 스티커, 출발 아래 자동차, 끝 깃발 위 발자국을 붙인다. 이미 붙인 게 있으면 묻고 바꾼다.
- 상단 **모두 떼기**: 이 카드의 스티커를 모두 뗀다(확인 후).
- 저장: 카드 한 장마다 따로, 기기에(shared_preferences, 키 `trip_card_stickers.v1`). "한 장에 모아보기"와 "하루씩 나눠보기"의 각 장은 배치가 달라 서로 다른 장으로 저장된다.
- 좌표는 카드 좌표(가로 358) 기준 스티커 중심·한 변 길이·회전(라디안).
- 카드와 스티커는 `RepaintBoundary` 안에 있어 이미지 저장·공유에 함께 담긴다. 고를 때 보이는 테두리는 바깥이라 담기지 않는다.
- 장소 눈금은 x 100~254 범위에만 놓아 반원 안쪽에 스티커 붙일 여백을 남긴다.

## 보기 방식

- **한 장에 모아보기**: 모든 날을 한 장에. 하단에 "다녀온 곳 N곳 · M일 동안"
- **하루씩 나눠보기**: 날마다 한 장, 폴더로 묶음. 2일차부터는 "숙소 출발", 끝은 "N일차 끝!"
- 당일 여행은 항상 한 장
- 종이: 모눈 / 점 / 무지
